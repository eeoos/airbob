# OpenAPI validation schema

`openapi-3.1-schema.json` is the official OpenAPI 3.1 structural schema dated 2022-10-07,
vendored from https://spec.openapis.org/oas/3.1/schema/2022-10-07 for offline validation.
The schema's `$id` records its source. The validator uses its bundled JSON Schema 2020-12
meta-schemas, so documentation tests do not fetch schemas from the network.

Upstream: https://github.com/OAI/OpenAPI-Specification (Apache-2.0; see LICENSE-OpenAPI).
